# Сайт BUY SUN: памятка для Claude

Сайт buysun.kz агентства BUY SUN (трудоустройство в отели Турции).

**Кому эти правила.** Раздел «Правки текстов и фото» ниже — для сессий, где
владелец сайта, Ахмед, просит поменять тексты, контакты или фото. Он не
программист: отвечай ему по-русски, простыми словами, без терминов, и если
просьба неясна (какой блок, какой текст), сначала переспроси. Разработчик
работает по обычным правилам проекта: коммиты `Feature:` / `Fix:` / `Docs:`,
описание в README и `deploy/README.md`.

## Правки текстов и фото

1. Найди блок по таблице ниже, поменяй только то, о чём просили. Остальной
   текст, вёрстку и стили не трогай.
2. Проверь (раздел «Перед тем как отдать правку»).
3. Коротко опиши по-русски, что изменилось: «было → стало», в каком блоке.
4. Коммит: `Content: <что изменилось>`. Описание pull request — по-русски, для
   Ахмеда, и последней строкой: «Сливать кнопкой **Squash and merge**».

После слияния в `main` сервер сам обновит сайт примерно за 5 минут. Если
сборка не проходит, он оставит прошлую версию.

### Контакты — только в `src/contacts.js`

Почта, телефоны, номер WhatsApp (для всех кнопок WhatsApp на сайте),
Telegram, TikTok, Instagram и адреса офисов записаны в одном файле
`src/contacts.js`; первый экран, подвал и блок контактов берут их оттуда.
Меняй контакты только там. Номер WhatsApp — только цифры с кодом страны, без
`+` и пробелов (`77026677171`); телефоны — как они показаны на сайте
(`+77777599489`). Ахмед может написать номер с пробелами или скобками —
сравнивай по цифрам.

### Фото

Ахмед загружает новое фото в репозиторий через GitHub, обычно в отдельную
ветку, и пишет, куда его поставить.

- **Новое имя, а не перезапись.** Браузеры держат картинки сайта неделю, и
  перезаписанный файл с тем же именем посетители увидят не сразу. Сохраняй
  под новым именем (латиницей, без пробелов, например `s6-2027.webp`) и меняй
  имя во **всех** местах, где стоит старое: `grep -rn "старое-имя" src/`
  (это находит и `.jsx`, и `.css`). Старый файл удаляй, только если `grep`
  больше ничего не находит.
- **Размер как у заменяемой картинки.** Узнай ширину старого файла и сделай
  новую такой же (фоны — 1920 px, лента логотипов `s8.webp` — 3824 px).
  Новое фото в галерею — около 1200 px по ширине. WebP, качество около 80.
- **Прозрачный фон не терять.** `man1.webp` (Ахмед, вырезанный по контуру
  поверх видео), `s8.webp` (логотипы) и все значки `*.png` держатся на
  прозрачности. Обычное фото с фоном сюда не годится: попроси у Ахмеда
  картинку PNG с прозрачным фоном и ничего не ставь, пока её нет.
- **Как конвертировать.** Например, Python Pillow, поставленный временно
  (`pip install pillow pillow-heif`), не в `package.json`. Обязательно
  `ImageOps.exif_transpose(img)` — иначе фото с телефона повернётся боком.
  Сохраняй без метаданных (без `exif=`): в фото с телефона бывают координаты.
  HEIC открывается через `pillow_heif.register_heif_opener()`.
- **Исходник** (большой JPG/PNG/HEIC, который загрузил Ахмед) удаляй из ветки,
  в репозитории остаётся только готовый WebP. Чтобы исходник не остался в
  истории, pull request сливается кнопкой **Squash and merge** (напиши это в
  описании).
- У картинок оставляй `alt`; в галерее он ставится сам по имени файла, это
  не трогай. Фото ниже первого экрана — с `loading="lazy"`.
- Новое видео первого экрана сам не подставляй: оно сжато в две версии,
  попроси Ахмеда передать его разработчику.

### Перед тем как отдать правку

1. `npm ci`, затем `npm run build` — без ошибок.
2. Каждая картинка, на которую ссылается сайт, существует. Сборка этого не
   проверяет, проверь сам:
   `grep -rhoE "/[A-Za-z0-9_.-]+\.(webp|png|jpg|mp4)" src | sort -u | while read f; do [ -f "public$f" ] || echo "нет файла: $f"; done`
   — команда не должна ничего вывести. Галерея собирает имена из списка в
   `Gallery.jsx`: для неё проверь, что каждый `s9-…` из списка лежит в
   `public/` с `.webp`.
3. В описании правки — что было и что стало, по блокам.

### Чего не трогать

Эти части связаны с сервером, базой, анкетами кандидатов и Битрикс24. Ошибка
в них ломает приём заявок. Если Ахмед просит поменять что-то здесь (даже
опечатку), объясни, что это работа для разработчика, и ничего не меняй:

- `server/`, `deploy/`, `admin/`, `src/admin/` — сервер, обновления, кабинет менеджеров;
- анкета целиком: `src/ResumeModal.jsx` (вопросы, подписи, варианты ответов —
  они продублированы в кабинете и в письмах), `src/anketaPdf.js`,
  `src/canvaPdf.js`, `src/anketaDraft.js`, `src/anketaLimits.js`,
  `src/PhotoField.jsx`, `src/photoUtils.js`, `src/pdfFonts.js`;
- `public/fonts/` и `public/logo_anketa.png` (логотип в PDF анкеты: нужен
  именно PNG, другой формат ломает отправку анкет);
- `src/api.js` и отправка форм;
- `package.json`, `package-lock.json`, `vite.config.js`, `index.html` — без
  новых библиотек и настроек;
- папка `materials/` — исходники, на сайт не попадают.

Никогда не добавляй в репозиторий анкеты, документы и личные данные
кандидатов, пароли и ключи. Фото людей для галереи — только те, что прислал
Ахмед для сайта.
